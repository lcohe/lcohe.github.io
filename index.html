What I've built

Employee Vehicle Checkout App

I built a web app to track employee use of company vehicles: who has a vehicle, where it's going, and when it's expected back. It tracks active and overdue checkouts, records returns, and includes searchable trip history and CSV exports.

This project gave me hands-on experience taking an app from local development to deployment. I built it with React and Firebase, using AI coding tools throughout the process. Drawing on my troubleshooting experience and understanding of systems, I worked to test the app and resolve issues until it was reliable and polished. It is now actively used in our day-to-day operations.

AI Troubleshooting Agent

I built a self-hosted AI agent to review troubleshooting tickets in monday.com, pull in relevant history, and send summaries to Slack. I built it to be able to reply to updates, change the status, and help assign issues to the appropriate Engineer. It ran on an Ubuntu server, with a Python webhook receiver and a Docker-based memory service.

This project gave me hands-on experience with Linux, Docker, networking, and keeping services running reliably. I eventually shut it down because maintaining it took about as much time as it saved. But it was a worthwhile learning project, and it taught me to consider the ongoing work behind an automation, not just whether or not I could get it running.
